# ФитПульс — запись на групповые тренировки

Дизайн и клиентская часть веб-приложения фитнес-студии: **регистрация → авторизация → заявки на тренировки → панель администратора**.

Выполнено в рамках производственной практики по ПМ.02 «Разработка дизайна веб-приложений».
Автор: Мамажонов Азамат Валижон Угли, группа ОКИП-12209МОвр.

**Демо:** https://ownids.github.io/fitpulse/

## Страницы
| Файл | Назначение |
|---|---|
| `index.html` | главная: направления, тренеры, цены, шаги записи |
| `register.html` | регистрация с валидацией (логин, пароль, ФИО, телефон с маской, email), проверка уникальности логина и email |
| `login.html` | вход, сообщение «Неверный логин или пароль» |
| `cabinet.html` | личный кабинет: новая заявка (тренировка, дата, время, оплата, комментарий) и список своих заявок со статусами |
| `admin.html` | панель администратора: статистика по статусам, поиск, фильтр, пагинация, смена статуса с уведомлением |

Тестовые входы: администратор **admin / FitPulse2026**, клиент **ivanova / pass123**.

## Технологии
HTML5 (семантическая разметка), CSS3 (mobile-first, Flexbox, Grid, медиазапросы 768/1024 px, анимации), JavaScript без фреймворков.
Данные хранятся в `localStorage` браузера и при первом открытии заполняются тестовым набором (`js/data.js`) — так прототип работает на GitHub Pages без сервера.

## Тестовые данные для БД
`database/test_data.sql` — структура БД MySQL (users, trainings, statuses, requests) и тестовый набор: 7 пользователей (пароли в виде хэшей), 5 тренировок, 4 статуса, 10 заявок.
Тот же набор в JSON: `data/test-data.json`.
```bash
mysql -u root -p < database/test_data.sql
```
